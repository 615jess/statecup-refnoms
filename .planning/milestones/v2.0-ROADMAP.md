# Milestone v2.0: Referee Nomination & Detail Collection

**Status:** SHIPPED 2026-03-23
**Phases:** 1-5.1 (6 phases)
**Total Plans:** 12

## Overview

v2.0 pivots from a DRA-provides-all workflow to a referee-provides-own-details workflow. The sheet schema is stabilized first so no subsequent phase writes to undefined or mis-validated columns. The DRA nomination form and its backend are simplified and verified with live sheet rows. The referee detail form and its full doGet/doPost backend — the core of v2.0 — are built against those verified rows. The assignor email admin page ships last because it embeds the finalized referee form URL into every mailto link.

## Milestone Summary

**Decimal Phases:**
- Phase 5.1: Parent/Guardian Email for Minors (inserted after Phase 5 for urgent feature request — minor referee safety)

**Key Decisions:**
- Pivoted from DRA-provides-all to referee-provides-own-details (2026-03-19)
- Token-in-URL for referee identity (no login needed)
- Mailto links for email (assignor uses Microsoft 365/Outlook, not Gmail)
- Spreadsheet columns for status tracking (no separate dashboard)
- Manual email trigger (assignor wants control)
- Late submissions allowed with flag + 3-day grace period
- Reuse existing token for re-nominated referees
- Referee can edit until deadline, then read-only
- Apps Script requires new deployment per code change
- DRA dropdown includes SRA and SYRA with auto-fill

**Issues Resolved:**
- v1.0 → v2.0 column schema migration (clean-slate rebuild)
- BooleanCriteria enum mismatch in verify script (TEXT_EQ → TEXT_EQUAL_TO)
- CORS-safe fetch patterns for Google Apps Script (no Content-Type header)
- Deployment URL fragmentation (3 different URLs → 1 consolidated URL)
- Placeholder email addresses replaced with production values
- REF_FORM_URL source/runtime mismatch resolved

**Issues Deferred:**
- SETUP-INSTRUCTIONS.txt is a stale v1.0 artifact (consider archiving)
- Column M stores a summary string not consumed downstream (by design)

**Technical Debt Incurred:**
- Minimal — 2 info-level items only, no blockers or warnings
