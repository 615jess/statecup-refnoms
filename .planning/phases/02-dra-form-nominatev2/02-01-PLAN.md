  <name>Task 1: Write nominatev2.gs — doPost handler with email dedup, token gen, LockService</name>
  <files>scripts/nominatev2.gs</files>
  <action>
Create `scripts/nominatev2.gs` with the following structure. Use the column index constants from COLUMN-MAP.md (COL_TIMESTAMP through COL_STATUS). The file must be ES5-compatible (var, no arrow functions, no template literals) to match the Phase 1 pattern.

**Top of file:** Column index constants (COL_TIMESTAMP = 1 through COL_STATUS = 19). Copy the exact constant block from COLUMN-MAP.md. Only include constants this file uses (A-H, Q, R, S).

**doPost(e):** Parse JSON from `e.postData.contents`. Check honeypot field (`payload.website`) — if present, silently return `{ ok: true, results: [] }`. Route `payload.action === 'nominateV2'` to `_handleNominateV2(payload.rows)`. Unknown actions return `{ ok: false, error: 'Unknown action' }`. Wrap everything in try/catch returning error as JSON.

**_handleNominateV2(rows):** Acquire `LockService.getScriptLock()` with `waitLock(15000)`. Inside try/finally (always release lock):
1. Get active spreadsheet and active sheet
2. Deduplicate within the submitted batch by email (last-wins for same email appearing twice). Rows without email always pass through.
3. Call `_loadEmailIndex(sheet)` to build `{email: rowNumber}` map from existing column H data
4. Loop through deduped rows. For each:
   - Normalize email: `(row.ref_email || '').trim().toLowerCase()`
   - If email exists in index: call `_updateDraColumns(sheet, existingRowNum, row)`, push `{ name: row.first + ' ' + row.last, status: 'updated' }` to results
   - If new: generate token via `Utilities.getUuid()`, call `_appendNewRow(sheet, row, token)`, update local email index with `sheet.getLastRow()`, push `{ name: row.first + ' ' + row.last, status: 'new' }` to results
5. Return `_jsonResponse({ ok: true, results: results })`

**_loadEmailIndex(sheet):** Read all values from column H (COL_REF_EMAIL), rows 2 through lastRow. Build `{normalizedEmail: rowNumber}` map. Return empty object if sheet has only header row.

**_updateDraColumns(sheet, rowNum, row):** Write columns A-H as a single 8-column range via `sheet.getRange(rowNum, COL_TIMESTAMP, 1, 8).setValues(...)`. Write column Q (DRA Notes) separately via `sheet.getRange(rowNum, COL_DRA_NOTES).setValue(...)`. NEVER touch columns I-P, R, or S. Timestamp is `new Date()` (let the sheet format it).

**_appendNewRow(sheet, row, token):** Build a 19-element array (columns A through S). Columns I-P (indices 8-15 in the array, which map to columns 9-16 in the sheet) are empty strings. Column Q = notes, R = token, S = 'Not Sent'. Use `sheet.appendRow(newRow)`. Timestamp is `new Date()`.

**_jsonResponse(obj):** Return `ContentService.createTextOutput(JSON.stringify(obj)).setMimeType(ContentService.MimeType.JSON)`.

**setTournamentConstants():** A standalone function the user runs once manually from the Apps Script editor. Uses `PropertiesService.getScriptProperties().setProperties(...)` to store:
- ASSIGNOR_EMAIL: 'jerickson@tnsoccer.org' (with comment to verify)
- WEEKEND_1_DATES: 'May 16 & 17, 2026'
- WEEKEND_2_DATES: 'May 23 & 24, 2026'
- REF_FORM_URL: 'TBD' (with comment: set after Phase 3 deployment)
Logs confirmation via `Logger.log()`.

**Important constraints:**
- ES5 syntax throughout (var, no const/let, no arrow functions, no template literals) — same pattern as setup-schema-v2.gs
- Timestamp: use `new Date()` — let Google Sheets handle the display format natively. Do NOT use toLocaleString.
- Column E (Referee #): Use `row.ref_num` as provided by the frontend. The frontend assigns sequential numbers.
- Do NOT include a doGet function — Phase 3 will add that later
- File header comment should note: "Phase 2: nominateV2 handler — paste into Apps Script editor alongside setup-schema-v2.gs"
