**doGet(e) function:**
- Extract token from `e.parameter.token` (trim, handle missing)
- If no token: return `_jsonResponse({ ok: false, error: 'missing_token', message: 'No token provided.' })`
- Otherwise: call `_handleGetDetails(token)`
- Wrap in try/catch: on error, log with `Logger.log` and return `_jsonResponse({ ok: false, error: 'server_error', message: 'An internal error occurred.' })` — do NOT expose raw error message to client

**_handleGetDetails(token) function:**
- Get active spreadsheet and sheet
- Token lookup: read column R (COL_TOKEN) from row 2 to lastRow as a single array via `getRange(2, COL_TOKEN, lastRow-1, 1).getValues()`. Loop to find match. If lastRow <= 1 or no match, return `{ ok: false, error: 'invalid_token', message: 'Token not found.' }`
- Read the full row: `sheet.getRange(rowNum, 1, 1, 25).getValues()[0]` — columns A through Y (25 columns, 0-indexed array)
- Read ConfirmationDeadline named range:
  - `ss.getRangeByName('ConfirmationDeadline')`
  - If null or not a valid Date: treat as `deadlineState = 'open'` (don't throw)
  - If valid Date: set to end-of-day (`deadlineVal.setHours(23, 59, 59, 999)`) before comparing
  - Calculate hardClose = deadline + 3 days in ms
  - `now > hardClose` => 'hard_closed'; `now > deadlineVal` => 'late'; else 'open'
  - Format deadline for display: `Utilities.formatDate(deadlineVal, Session.getScriptTimeZone(), 'MMMM d, yyyy')`
- Read PropertiesService: `ASSIGNOR_EMAIL`, `WEEKEND_1_DATES`, `WEEKEND_2_DATES`
- Return JSON response with all fields (use 0-based array indexing from rowData):
  ```
  {
    ok: true,
    deadlineState: deadlineState,
    deadlineDisplay: deadlineDisplay,
    firstName: String(rowData[5] || ''),    // F
    lastName: String(rowData[6] || ''),     // G
    refEmail: String(rowData[7] || ''),     // H
    draName: String(rowData[1] || ''),      // B
    draEmail: String(rowData[2] || ''),     // C
    status: String(rowData[18] || ''),      // S (0-based index 18)
    submittedAt: rowData[20] ? String(rowData[20]) : '',  // U
    phone: String(rowData[8] || ''),        // I
    age: String(rowData[9] || ''),          // J
    availability: String(rowData[12] || ''), // M
    gender: String(rowData[13] || ''),      // N
    hotelWkd1: String(rowData[14] || ''),   // O
    hotelWkd2: String(rowData[15] || ''),   // P
    refWeekend1: String(rowData[21] || ''), // V
    refWeekend2: String(rowData[22] || ''), // W
    lateFlag: String(rowData[23] || ''),    // X
    refNotes: String(rowData[24] || ''),    // Y
    weekend1Dates: props.getProperty('WEEKEND_1_DATES') || '',
    weekend2Dates: props.getProperty('WEEKEND_2_DATES') || '',
    assignorEmail: props.getProperty('ASSIGNOR_EMAIL') || ''
  }
  ```

7. Write referee-provided columns:
   - Phone (I=9): `sheet.getRange(rowNum, COL_PHONE).setValue(payload.phone || '')`
   - Age (J=10): `sheet.getRange(rowNum, COL_AGE).setValue(payload.age || '')`

   - RefWeekend1, RefWeekend2, LateFlag, RefNotes (V-Y = 22-25) as one range:
     LateFlag logic: `(deadlineState === 'late' && isFirstSubmission) ? 'Y' : (existing lateFlag value or '')`
     CRITICAL: If this is an EDIT (not first submission), preserve the existing LateFlag value. Read it before writing: `var existingLateFlag = sheet.getRange(rowNum, COL_LATE_FLAG).getValue() || '';`

   - Status (S=19): `sheet.getRange(rowNum, COL_STATUS).setValue('Confirmed')`
   - SubmittedAt (U=21): `sheet.getRange(rowNum, COL_SUBMITTED_AT).setValue(new Date())`
9. Return: `{ ok: true, lateFlag: lateFlag || null }`
