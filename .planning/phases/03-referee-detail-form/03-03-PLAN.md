   ```
   }
   ```

   ```
   if (payload.action === 'submitDetails') {
     return _handleSubmitDetails(payload);
   ```

7. Save all files (Ctrl/Cmd + S)

   - Who has access: Anyone
9. Click Deploy
10. Copy the new Web app URL (the /exec URL)

  <how-to-verify>
**Prerequisites:** At least one nominee row must exist in the Google Sheet (from Phase 2 DRA form). The row must have a token in column R.

**Test 1 — Valid token, first visit:**
1. Get a valid token from column R of a nominee row in the sheet
2. Open `referee-details.html?token=YOUR_TOKEN` (locally or via GitHub Pages)
3. VERIFY: Loading spinner shows briefly, then the form appears
4. VERIFY: Personalized greeting shows the referee's first name and DRA name
5. VERIFY: Tournament dates (Weekend 1: May 16-17, Weekend 2: May 23-24) are displayed
6. VERIFY: Assignor contact email is shown
7. VERIFY: Submit button says "Submit Details" (not "Update Details")

**Test 2 — Form submission:**
1. Select Yes for Weekend 1 — VERIFY: Hotel question for Weekend 1 appears
2. Select No for Weekend 2 — VERIFY: Hotel question for Weekend 2 is hidden
3. Select Yes for Weekend 1 Hotel
4. Enter age, select gender, enter phone number
5. Type a note in the notes field
6. Click "Submit Details"
7. VERIFY: Button shows spinner during submission
8. VERIFY: Success state appears with a summary of submitted values
9. Check the Google Sheet — VERIFY:
   - Column I (Phone) has the phone number
   - Column J (Age) has the age
   - Column M (Availability) has "Yes / No"
   - Column N (Gender) has the selected gender
   - Column O (Hotel Weekend 1) has "Yes"
   - Column P (Hotel Weekend 2) is empty (Weekend 2 was No)
   - Column S (Status) is "Confirmed"
   - Column U (SubmittedAt) has a timestamp
   - Column V (RefWeekend1) has "Yes"
   - Column W (RefWeekend2) has "No"
   - Column Y (RefNotes) has the note text

**Test 3 — Return visit (pre-fill):**
1. Re-open the same token URL
2. VERIFY: Form loads with all previously submitted data pre-filled
3. VERIFY: Weekend 1 toggle shows "Yes" active, Weekend 2 shows "No" active
4. VERIFY: Hotel Weekend 1 section is visible with "Yes" selected
5. VERIFY: Hotel Weekend 2 section is hidden
6. VERIFY: Submit button says "Update Details"

**Test 4 — Invalid token:**
1. Open `referee-details.html?token=INVALID_TOKEN_ABC`
2. VERIFY: Error state shows "Token not found" message with assignor contact
3. VERIFY: No 500 error or raw HTML error page

**Test 5 — Missing token:**
1. Open `referee-details.html` (no token parameter)
2. VERIFY: Error state shows "No token" message

**Test 6 — Mobile responsiveness:**
1. Resize browser to < 560px width (or use mobile emulation)
2. VERIFY: Single column layout, all text readable, toggle buttons are large enough to tap
