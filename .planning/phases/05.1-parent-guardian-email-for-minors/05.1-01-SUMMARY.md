# Phase 5.1 Plan 01: Parent/Guardian Email Backend Support Summary

**One-liner:** Column AB (Parent/Guardian Email) added to sheet schema, refdetails.gs read/write endpoints, and adminemail.gs getAllNominees with COL_PARENT_EMAIL = 28 constant.

## What Was Built

Backend support for storing and retrieving a parent/guardian contact email for minor referees. This is a prerequisite for the frontend conditional field (Plan 05.1-02).

### Changes by File

**scripts/refdetails.gs**
- Added `COL_PARENT_EMAIL = 28` constant (column AB)
- Expanded `_handleGetDetails` `getValues` range from 25 to 28 columns (A through AB)
- Added `parentEmail: String(rowData[27] || '')` to `_handleGetDetails` response object
- Added Step 9 write in `_handleSubmitDetails`: `sheet.getRange(rowNum, COL_PARENT_EMAIL).setValue(payload.parentEmail || '')`
- Updated file header COLUMN REFERENCES USED and COLUMN CONSTANTS IN THIS FILE sections

**scripts/adminemail.gs**
- Expanded `_handleGetAllNominees` `getValues` range from 25 to 28 columns (A through AB)
- Added `age: String(r[9] || '')` and `parentEmail: String(r[27] || '')` to nominee object mapping
- Updated file header COLUMN REFERENCES USED section with J and AB entries

**scripts/setup-schema-v2.gs**
- Added `COL_PARENT_EMAIL = 28` constant (AB)
- Extended `HEADERS_V2` array from 26 to 28 entries: added `''` at index 26 (AA) and `'Parent/Guardian Email'` at index 27 (AB)
- Expanded `_rebuildHeaderRow` `setValues` range from 26 to 28 columns
- Expanded `_clearDataRows` `clearContent` range from 26 to 28 columns
- Updated COLUMN INDEX REFERENCE comment block to include AB

**.planning/COLUMN-MAP.md**
- Added AA and AB rows to Column Map A-Z table
- Added `COL_PARENT_EMAIL = 28` to Column Index Constants code block
- Added AB to the Referee form writer row in Column Writer Summary
- Added Column AB usage note (written only for minor referees, blank for adults)
- Updated last updated date to 2026-03-23

## Decisions Made

| Decision | Choice | Rationale |
|----------|--------|-----------|

| AA entry in HEADERS_V2 | `''` (blank) at index 26 | AA label is written separately in `_rebuildHeaderRow` idempotency block; keeping as blank in array ensures setValues covers it without clobbering |
| age field added to getAllNominees | Yes, added `age: r[9]` | Admin page (Plan 05.1-03) needs age to conditionally display parentEmail; adding now avoids a second backend change |
