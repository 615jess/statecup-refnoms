Output: Updated admin.html with a toggle button next to the search box that filters the table to show only Not Sent nominees when active.

  4. **Add statusFilter state variable** — In the STATE section (around line 268, after `var searchQuery = '';`), add:
     ```javascript
     var statusFilter = ''; // '' = show all; 'Not Sent' = filter to Not Sent only
     ```

  5. **Add toggleNotSentFilter function** — After the searchQuery input listener in the DOMContentLoaded block (but can also be a standalone function outside it), add:
     ```javascript
     function toggleNotSentFilter() {
       statusFilter = (statusFilter === 'Not Sent') ? '' : 'Not Sent';
       var btn = document.getElementById('btn-filter-not-sent');
       if (statusFilter === 'Not Sent') {
         btn.classList.add('active');
         btn.textContent = 'Not Sent Only \u2713';
       } else {
         btn.classList.remove('active');
         btn.textContent = 'Show Not Sent Only';
       }
       renderTable();
     }
     ```

  6. **Add statusFilter to renderTable()** — In the renderTable function, after the existing searchQuery filter block (lines 384-389), add the status filter:
     ```javascript
     // Apply status filter (if active)
     if (statusFilter) {
       filtered = filtered.filter(function(n) {
         return (n.status || 'Not Sent') === statusFilter;
       });
     }
     ```
     This uses the same `|| 'Not Sent'` fallback already established on line 427 of the current code.

  7. **Update no-results message** — In the no-results check (line 414), update the message to account for active filter:
     ```javascript
     noCell.textContent = (searchQuery || statusFilter) ? 'No nominees match your search.' : 'No nominees found.';
     ```
