  Add the `_handleGetDRANominees` function at the end of adminemail.gs (after `_handleMarkSent`).

  The function accepts a `draName` parameter (string or empty/null):

  **When draName is empty/null — return distinct DRA names:**
  1. Get active spreadsheet and sheet
  2. If no data rows (lastRow <= 1), return `{ ok: true, draNames: [] }`
  3. Read column B (DRA Name) for all data rows: `sheet.getRange(2, COL_DRA_NAME, dataRowCount, 1).getValues()`
  4. Extract distinct non-empty DRA names, sorted alphabetically
  5. Return `{ ok: true, draNames: [...] }`

  **When draName is provided — return filtered nominees:**
  1. Get active spreadsheet and sheet
  2. If no data rows, return `{ ok: true, nominees: [], counts: { responded: 0, pending: 0 } }`
  3. Read all data rows (A through AB = 28 columns) in a single API call (same pattern as _handleGetAllNominees)
  4. Filter rows where `r[1]` (0-based index for column B) matches `draName` exactly (String comparison)
  5. Map each matching row to a nominee object with these fields (all String cast with `|| ''` fallback):
     - `firstName`:    `String(r[5]  || '')` — F (0-based 5)
     - `lastName`:     `String(r[6]  || '')` — G (0-based 6)
     - `status`:       simplified status (see below)
     - `phone`:        `String(r[8]  || '')` — I (0-based 8)
     - `age`:          `String(r[9]  || '')` — J (0-based 9)
     - `availability`: `String(r[12] || '')` — M (0-based 12)
     - `gender`:       `String(r[13] || '')` — N (0-based 13)
     - `hotelWkd1`:    `String(r[14] || '')` — O (0-based 14)
     - `hotelWkd2`:    `String(r[15] || '')` — P (0-based 15)
     - `refWeekend1`:  `String(r[21] || '')` — V (0-based 21)
     - `refWeekend2`:  `String(r[22] || '')` — W (0-based 22)
     - `refNotes`:     `String(r[24] || '')` — Y (0-based 24)
  6. Status simplification: read raw status from `String(r[18] || '')` (column S, 0-based 18):
     - `'Confirmed'` → `'Responded'`
     - anything else (`'Not Sent'`, `'Sent'`, or blank) → `'Pending'`
  7. Count responded and pending nominees
  8. Return `{ ok: true, nominees: [...], counts: { responded: N, pending: M } }`

  Add a JSDoc header comment following the same style as `_handleGetAllNominees` and `_handleMarkSent`. Include column references used.

  **Do NOT include:** refEmail, token, sentAt, submittedAt, lateFlag, parentEmail, draName, draEmail, district — these are excluded per 07-CONTEXT.md decisions.
