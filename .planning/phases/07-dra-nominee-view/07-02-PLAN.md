  **loadDRANames():**
  1. Show loading state
  2. `fetch(SCRIPT_URL + '?action=getDRANominees')` — no draName param
  3. Parse response, populate `#dra-select` with `<option>` for each DRA name
  4. Check localStorage for `draNomineeView_selectedDRA`
  5. If found and matches a dropdown option, select it and call `loadNominees(savedName)`

  **onDRASelect():**
  1. Get selected DRA name from dropdown
  2. If empty (placeholder selected), hide nominee-area, return
  3. Save to localStorage: `draNomineeView_selectedDRA`
  4. Call `loadNominees(draName)`

  **loadNominees(draName):**
  1. Show a brief loading indicator in the nominee area (or the full loading state)
  2. `fetch(SCRIPT_URL + '?action=getDRANominees&draName=' + encodeURIComponent(draName))`
  3. Parse response, store in `nominees` and `counts`
  4. Call `renderSummary()` and `renderTable()`
  5. Show nominee-area

  - Build summary bar: "X nominees — Y responded, Z pending"
  - Use badge spans for responded (green) and pending (gray) counts

  - Clear tbody
